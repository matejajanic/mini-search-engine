# Hybrid Search + RAG Mini Project

This project implements a small end-to-end retrieval pipeline including:

- document chunking
- sparse retrieval (TF-IDF)
- dense retrieval (SentenceTransformers)
- FAISS vector index
- hybrid retrieval
- cross-encoder reranking
- simple RAG-style answer synthesis

The goal is to understand how modern search / retrieval systems work.
